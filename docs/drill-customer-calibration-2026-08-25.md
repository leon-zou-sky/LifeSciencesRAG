# 客户标定全流程演练记录（2026-08-25）

> 独立演练文档，不属于设计/调研文档体系。
> 性质：交付前彩排 + 负对照实验。目的不是证明"系统好用"，而是故意制造事故，验证闸门和留痕机制在真出事时的行为。

## 0. 演练设计

模拟场景：某客户医学信息部提供 16 对自有标注对，要求为其数据标定问询判重阈值。

完整链路（四步）：

```
客户 CSV → import_calibration_pairs.py → calibration_report.py → set_threshold.py → regression.py 终审
```

另加两段**负对照实验**（明知是坏值故意设进 DB，验证终审是否拦截）：

- 一阶段：duplicate 0.85 → 0.75（打判重线）
- 二阶段：new 0.70 → 0.50（打新问线）

## 1. 客户标定链路（顺利通过）

客户数据：16 对（同问题 8 / 异问题 8，含难负样本），见 `data/customer_calibration/customer_pairs.csv`。

标定报告（`reports/calibration_report_20260825_082319.md`）关键结论：

| 指标 | 值 |
|---|---|
| 可分性 | 不可分（代理指标层面，F1=0.875 > 0.70 退出线） |
| 推荐 duplicate | 0.8416（F1 最优点） |
| 推荐 new | 0.7637（负簇分位点，防倒挂保护生效） |
| 现役值 | duplicate=0.85 / new=0.70 |

应用推荐值后 regression 终审**通过**——黄金集接受区比预期宽（0.8416 与 0.85 均在安全区内），但格华止探针余量从 0.067 缩到 0.0036，故回滚保留现役值。

## 2. 事故：漏回滚导致混合态（审计链抓到）

**经过**：首次回滚只跑了 inquiry.new，duplicate 停在 0.8416——系统处于"一半演练值一半现役值"的混合态。

**为什么回归没发现**：回归输出的 score 列是向量检索分数，与阈值无关；阈值只参与档位判定，而两套阈值下全部探针判定恰好都绿。**回归输出对阈值配置不敏感，不能用作状态核验依据。**

**怎么发现的**：`set_threshold.py --history` 对账发现缺第三条回滚记录。

**教训**：
- 配置状态核验只能查 `threshold_history`（审计表），不能靠行为测试反推
- runbook 缺陷①：演练缺"结束后 DB 值 == 预期锚定值"的自动对账断言（已记待办⑪）
- runbook 缺陷②：回滚理由被预填模板污染（写了"终审未过"实际通过）——**理由栏必须由操作人按实际结果填写，禁止预填**

## 3. 负对照一阶段：duplicate 0.75（失败——但败得有价值）

**预期**：3 条灰色探针（立普妥 0.8098 / 他汀类 0.7851 / 格华止 0.7673）≥0.75 被误判 duplicate，回归红。

**实际**：全绿。

**根因**（代码层复现确认）：

```
立普妥   0.8098 → gray  guarded=True（药品集合不一致，护栏强制降人工闸）
他汀类   0.7851 → gray  guarded=True
格华止   0.7673 → gray  guarded=True
```

三条灰色探针**全是护栏探针**——分数过了坏阈值线，但药品集合护栏（dedup_guard）独立地把它们按回人工闸。**篡改第一道闸（阈值），第二道闸（护栏）兜住了全部攻击。**

**侧证**：判定理由显示"向量分 0.8098 过判重线"（0.8098 < 0.85，若读的是旧值不会"过线"）——证明 DB 新值 0.75 确实被回归读到了，加载链路无罪。

**结论**：这不是闸失灵，是**纵深防御生效的实证**。同时暴露方法论盲区：多层防御系统的负对照必须**单层单测**，打哪层就得绕过另一层。

## 4. 负对照二阶段：new 0.50（成功拦截）

换打 new 线（该层探针无护栏保护）：

```
❌ 二甲双瓜缓释片怎么吃      0.6450  期望 new  实际 gray
❌ 华法令和可达龙一起吃      0.5341  期望 new  实际 gray
回归失败 2 项，退出码非零
```

**结论**：终审是真闸——单层坏值进来，对应层的探针必翻。

## 5. 闸灵敏度图谱（本次演练的最硬产出）

| 被篡改的键 | 敏感探针 | 兜底机制 | 负对照结果 |
|---|---|---|---|
| inquiry.duplicate | 灰色探针全是护栏探针 | 药品集合护栏独立兜底 | 回归不红（护栏扛住） |
| inquiry.new | 二甲双瓜/华法令（非护栏探针） | 无兜底，直探阈值 | 回归红 2 条 ✅ |

**交付话术**：我们不只是声称闸门有效，而是故意弄坏它、记录它怎么拦。duplicate 线被篡改时护栏兜底，new 线被篡改时回归报警——每层都有独立的最后防线。


最终状态：duplicate=0.85 / new=0.70（现役锚定值），回归 10/10 绿。
